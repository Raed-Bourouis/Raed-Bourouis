## 🔧 What I'm Working On


🚀 **MLEASE** — an end-to-end time series forecasting pipeline  
A full-stack project that allows users to:
- Upload and manage multiple datasets
- Automatically explore, preprocess, and visualize data
- Choose from models like SARIMA, Prophet, XGBoost, LSTM, or an ensemble
- Train and evaluate models with experiment tracking powered by **MLflow**

📚 Built with: Python, Pandas, Scikit-learn, TensorFlow, Matplotlib, MLflow

🛠️ Tech highlights:
- Intelligent model recommendation engine
- Modular design for extensibility
- Clean UI to manage datasets and workflows
