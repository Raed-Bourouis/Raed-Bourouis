## 🚀 Featured Projects
 
### RPAWatch — Agentic Dispute-Tracking System
*Final-year internship project @ Talan Tunisie Consulting*
 
An observability system that tracks dispute cases across chains of  **RPA robots**, built around a **LangGraph agentic reasoning pipeline**.
 
- 🔍 Resolves heterogeneous case identifiers into a single canonical `case_uid` — entity resolution across identifier namespaces was the core technical challenge
- 🧠 LangChain + Azure OpenAI (GPT-4o, text-embedding-3-large) for reasoning and retrieval, with pgvector for semantic search
- 🗄️ PostgreSQL + SQLAlchemy/Alembic for data modeling and migrations
- ⚙️ FastAPI backend, react dashboard, Docker Compose for deployment, Langfuse for LLM observability
- 🎯 Core framing: the *dispute case* is the unit of analysis, not the robot — the system answers "where is dispute #X right now?"
**Stack:** Python 3.11 · LangGraph · LangChain · Azure OpenAI · PostgreSQL/pgvector · FastAPI · Streamlit · Docker · Langfuse

### MLEASE — End-to-End Time Series Forecasting Pipeline
 
A full-stack platform for automated time series forecasting:
 
- 📊 Upload and manage multiple datasets with automatic EDA, preprocessing, and visualization
- 🤖 Intelligent model recommendation engine across SARIMA, Prophet, XGBoost, LSTM, and ensemble methods
- 📈 Experiment tracking and model comparison powered by **MLflow**
- 🧩 Modular design built for extensibility
**Stack:** Python · Pandas · Scikit-learn · TensorFlow · Matplotlib · MLflow
